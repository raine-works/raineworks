# raineworks.com documentation

The source of raineworks.com: a Hono server compiled to one binary, prerendered React 19 zones, and the same content
in a terminal over SSH.

| Guide | What it covers |
| :--- | :--- |
| [Architecture](architecture.md) | The packages, the zones, how the server serves them, and production |
| [Development](development.md) | Setting up, the commands, testing, releases, Claude in GitHub and deployment |
| [Frontend](frontend.md) | A zone, prerendering, the design system, the About dialog, versions and the build |

The rules for changing the repository are in [AGENTS.md](../AGENTS.md), the code style in
[STYLEGUIDE.md](../STYLEGUIDE.md), and setup and the package map in the [README](../README.md).
